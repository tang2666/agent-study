# 99 — 试验田

**这里没有规矩。**

随手乱写的地方：试个奇怪的想法、复现一个看到的效果、验证一个"这到底行不行"的猜想。

不用写 README、不用守命名规范、不用管代码质量、可以直接删。

唯一的要求：**想扔掉的代码先扔这儿，不要在正式目录里做实验污染它们。**

## 顺手记的东西

如果实验做出了有意思的结论，值得记下来的话，可以在这儿随手留一行：

```markdown
## 2026-09-24
试了 XX。结论：YY。原因大概是 ZZ。
```

攒多了自然会知道哪些该整理进 `90-notes`。

## 一些适合扔进来的问题

不用急着回答，随手试就好：

- 同一个问题问两次，答案差多少？（采样随机性）
- 把 `effort` 拉到最低，简单任务的答案会变差吗？
- 工具描述写得很短 vs 写得很长，模型选择工具的准确率差多少？
- 系统提示词里加一句毫无意义的废话，会影响输出吗？（缓存会怎样？）
- 上下文里塞一些完全不相关的内容，答案质量会掉多少？
- 模型说自己"不能做某事"，是真的不能，还是提示词的问题？
